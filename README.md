# 🐠 BlurFin Platform

관상어 경매/거래 플랫폼

## 🏗️ 프로젝트 구조

```
blurfin-dev/
├── apps/
│   ├── web/          # Next.js 프론트엔드
│   └── api/          # Express 백엔드
└── packages/         # 공통 패키지
```

## 🚀 개발 시작

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

## 🛠️ 기술 스택

- **Frontend**: Next.js + TypeScript + Tailwind CSS
- **Backend**: Express.js + TypeScript
